About WinAPI Atlas

WinAPI Atlas maps Windows API functions to malware technique categories, MITRE ATT&CK techniques and behavioural telemetry. It is a reference for malware analysts, SOC analysts and detection engineers — not an execution toolkit.

Mapping mode

Turn on Mapping mode, then click APIs in any column. APIs that appear in several columns highlight everywhere. The floating panel counts the selection, breaks it down per category and scores known technique chains from data/presets.json.

Paste imports

Paste dumpbin /imports, rabin2 -i, PEStudio output or a list of strings. Matching runs locally, recognises A/W/Ex variants and turns every hit into a mapping selection.

Keyboard

  • / focus search
  • Esc leave search or close a dialog
  • M toggle mapping mode
  • Tab move between filters, columns and API cards

How to read an entry

Suspicion describes how suspicious the API is on its own, not how likely the binary is malicious. Most APIs are used by ordinary software every day, so detection guidance focuses on context, correlation and telemetry.

Data and verification

Entries marked verified are documented Win32 APIs with Microsoft Learn coverage. Native Nt*/Zw*/Rtl* entries marked unverified are exported and widely used, but their behaviour is not described by a public per-function reference page.

Shareable state

Search, filters, selection and theme are encoded in the URL hash, and the open entry uses ?api=Name. Copy Copy Link in an entry dialog to share it. Plain category links such as ?cat=injection open that column directly.
